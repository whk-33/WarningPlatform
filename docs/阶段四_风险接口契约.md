## 2. parquet 字段契约（9 字段，冻结）

`stu_id / course_code / semester / week(int8,0-15) / risk_prob(float32,0-1) / risk_level(int8,0/1/2) / risk_level_name(低/中/高) / pred_event_week(int8,-1=学期内无风险) / top_factors(JSON 字符串)`

- `week` 一律 0 起，前端展示层 `+1`；后端不改写
- `risk_prob` 0-1 概率空间，前端转百分数
- `pred_event_week = -1` 是语义值不是 bug
- `top_factors` 建议后端 `json.loads` 成数组再返回（B5）；contrib 可能 <100%，**前端不要强制归一**

## 3. 五个风险接口

### 3.1 `GET /api/risk/weekly?stu_id&course_code&semester&week`
单周风险。响应样例见 [mock_api/weekly.json](mock_api/weekly.json)。
字段 = parquet 9 字段中 8 个（`top_factors` 解析为数组）。

### 3.2 `GET /api/risk/student/{stu_id}?semester=`
全学期曲线，**一次返回数组**（F1：不要前端循环 16 次）。样例见 [mock_api/student.json](mock_api/student.json)。
`weeks[]` 每元素含 `week/risk_prob/risk_level/risk_level_name/pred_event_week/top_factors/course_code`；多门课取当周最高风险那门（与推理桥 `predict_student` 同口径）。

### 3.3 `GET /api/risk/factors?stu_id&course_code&semester&week`
归因。样例见 [mock_api/factors.json](mock_api/factors.json)。
`top_factors[]`：`{factor, value, contrib}`，最多 3 个，按 contrib 降序。

### 3.4 `GET /api/admin/risk/list?semester&week&level&page&size`
管理员分页列表，按 `risk_prob` 降序。样例见 [mock_api/admin_list.json](mock_api/admin_list.json)。
`level` 可选过滤 0/1/2；响应含 `page/size/total/items[]`。

### 3.5 `GET /api/admin/risk/stat?semester&week`
等级分布。样例见 [mock_api/admin_stat.json](mock_api/admin_stat.json)。
`alert_rate = (level_1 + level_2) / total`。

## 4. 推理桥（新学生兜底，B6）

```bash
# 三模式（stdout 单行 JSON，成功 exit 0；失败 exit 1 且输出 {"error","mode"}）
python algorithm/src/serving/30_online_risk.py weekly   --stu_id <id> --course_code <c> --semester <s> --week <0-15>
python algorithm/src/serving/30_online_risk.py student  --stu_id <id> --semester <s>
python algorithm/src/serving/30_online_risk.py subgraph --stu_id <id> --semester <s> [--week 8]
```

- **后端进程不要 import torch**：只 subprocess 调用，模型内存在子进程结束即释放
- 延迟：缓存命中约 15ms，新学生首次约 800ms；建议后端设 5s 超时 + 404 兜底
- 环境前置：需要含 torch 的 Python（团队约定解释器）；torch DLL 被系统策略拦截的机器无法运行，部署服务器需提前验证 `python -c "import torch"`
- 错误契约：exit≠0 或 stdout 含 `error` 键 → 后端按 503/404 处理，不要解析半截 JSON

## 5. 数据源切换（真实数据试点）

1. 新数据按 `docs/数据字段约定.md` 清洗后放入新目录（如 `processed_school_v1/`）
2. 依次跑 `20_score_offline.py`（打分）→ `32_quality_checks.py`（PSI 门禁）→ 通过后原子替换 `risk_scores.parquet`（`31_weekly_run.py` 已封装此流水线）
3. 后端用 `WP_PROCESSED` 指向新目录，无需改代码
4. PSI > 0.25 时门禁阻断、保留旧表，阈值强制重校（C4：目标预警率 15%±5%）
